Meta characters

Pattern Desc
^ 문자열 시작
$ 문자열 종료
. 개행문자를 제외한 임의의 문자 (한개)
* Wildcard
+ 앞의 문자가 x>1
? 앞의 문자가 x<1
[] 문자의 집합 또는 범위
{} 괄호안의 문자를 하나의 문자로 처리
| OR
\s 공백 [ \t\n\r\f\v]
\S 공백이 아닌 문자 [^ \t\n\r\f\v]
\w 알파벳+숫자 [a-zA-Z0-9_]
\w 알파벳+숫자를 제외한 문자 [^a-zA-Z0-9_]
\D 숫자를 제외한 모든 문자 [^0-9]
\ 일반적으로 사용되는 \의미와 동일함 표현할 수 없는 문자를 표현할 떄 사용
(?i) 대소문자 구별하지 않음
.* 줄 전체 선택 (e.g abcd.* => abcd1234도 매치됨 )
