JWT-HACK

JUNE 6, 2025
EN KO

JSON Web Token Hack Toolkit

# Cargo
cargo install jwt-hack

# Brew
brew tap hahwul/jwt-hack
brew install jwt-hack

JWT-HACK은 JWT(JSON Web Token)을 분석하기 위한 CLI 도구로 encode, decode, verify, crack 그리고 payload 모드를 지원합니다. 각각 모드를 사용하여 jwt를 분석하고 보안 취약점을 찾을 수 있도록 돕는 도구입니다.
