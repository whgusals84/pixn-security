Urx

MARCH 31, 2025
EN KO

Extracts URLs from OSINT Archives for Security Insights

# Cargo
cargo install urx

# Brew
brew tap hahwul/urx
brew install urx

Urx는 Wayback Machine 및 Common Crawl과 같은 OSINT 아카이브에서 URL을 수집하기 위해 설계된 Command line 도구입니다. 효율성을 위해 Rust로 제작되었으며, 비동기 처리를 활용하여 여러 데이터 소스를 빠르게 쿼리합니다. 이 도구는 지정된 도메인에 대한 URL 정보를 수집하는 프로세스를 단순화하여 보안 테스트 및 분석을 포함한 다양한 목적으로 사용할 수 있는 포괄적인 데이터 세트를 제공합니다.
