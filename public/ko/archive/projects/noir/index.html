OWASP Noir

AUGUST 3, 2023
EN KO

Attack surface detector that identifies endpoints by static analysis.

Github • Documentation • OWASP Project 

brew install noir

OWASP Noir는 WhiteBox 보안 테스트 및 보안 파이프라인을 위한 공격 표면 식별을 목적으로 하는 오픈 소스 프로젝트입니다. 보안 분석을 위해 소스 코드 내에서 API 엔드포인트, 웹 엔드포인트 및 기타 잠재적 진입점을 검색하는 기능을 가지고 있습니다.

이 도구는 Crystal을 사용하여 개발되었습니다. 처음에는 2023년 8월에 내 개인 프로젝트로 시작되어 2024년 6월에 저와 ksg가 공동 주도하는 OWASP 프로젝트가 되었습니다.
