Transform text. Instantly.

TextNova is a powerful text transformation tool, and on Mac a lightweight editor, built for developers. Instantly convert, encode, decode, hash, and format text with 145 built-in transformers, all in one clean, fast interface.

On-Device AI

Powered by Apple Intelligence, TextNova brings smart text transformations without compromising your privacy. All AI processing happens entirely on your device.

  • Summarize — Condense long text into key points
  • Fix Grammar — Correct spelling, grammar, and punctuation
  • Translate — Translate text between languages
  • Simplify / Expand — Adjust the level of detail
  • Tone Control — Switch between formal and casual styles
  • Bullet Points — Convert paragraphs into structured lists
  • Explain Code — Get plain-language explanations of code
  • Custom Prompts — Write your own AI instructions for unlimited possibilities

145 Built-in Transformers

No network required. Fast, reliable, and always available.

Encoding & Decoding

Base64, Base32, Base45, Base58, Base62, Base85, URL encoding, Hex, Binary, Gray code, Octal, Roman numerals, Unicode, Punycode, JWT decode, Morse code, ROT5/13/18/47, Bacon cipher, Quoted-Printable, and more.

Hashing

MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC16, CRC32, Adler-32, and FNV-1a.

Formatting

JSON / XML pretty print & minify, YAML ↔ JSON, TOML conversion, HTML escape, Markdown to HTML.

Case Conversion

UPPERCASE, lowercase, Title Case, camelCase, snake_case, kebab-case, PascalCase, dot.case.

Text Utilities

Extract URLs / emails / IPs, strip HTML tags, add/remove line numbers, sort & deduplicate lines, UUID generator, character frequency analysis, Shannon entropy, and more.

Data & Date/Time

CSV ↔ JSON, CSV ↔ Markdown tables, chmod permissions (octal ↔ symbolic), RGB ↔ HSL color, Number to Words, Unix timestamp conversion, ISO 8601 formatting, and Lorem Ipsum generator.

A Lightweight Editor on Mac

On macOS, TextNova is more than a single buffer. Open files and folders in a file-tree sidebar, work across document tabs, and run any transform on the active document. Everything you edit stays local.

  • Files & Folders — A collapsible file-tree sidebar with create, rename, reorder, and delete
  • Document Tabs — Work across multiple wrapping documents at once
  • External-Change Detection — Reload on disk changes, with a quit guard so nothing is lost
  • Syntax & Diff — Highlighting and a built-in diff view for reviewing transforms

Designed for Power Users

  • Command Palette — Search and launch any transformer instantly
  • Files & Tabs (Mac) — Open files and folders in a file-tree sidebar and work across document tabs
  • Undo / Redo — Full transformation history
  • Customizable Fonts — SF Mono, Menlo, Monaco, and more
  • Line Numbers & Wrapping — Tailored editing experience
  • Keyboard-Driven — Navigate and transform without touching the mouse
  • Clipboard Auto-Detect — Start transforming the moment you copy text
  • Session Restore — Pick up right where you left off

Available in 9 Languages

English, Korean, Japanese, Simplified Chinese, Traditional Chinese, Spanish, French, German, and system default.

Privacy First

TextNova does not collect, store, or transmit any personal data. All AI processing is handled on-device by Apple Intelligence. Your text stays on your device — always.
