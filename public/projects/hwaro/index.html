Hwaro

Capabilities

Small footprint, full-featured

Hwaro processes Markdown with TOML, YAML or JSON front matter and Jinja2-compatible templates, then bundles a fast, SEO-ready site — no plugins required.

01

Multi-threaded builds

Parallel processing and incremental caching keep builds fast as the site grows.

02

Jinja2 templating

Template inheritance, macros and custom shortcodes, powered by Crinja.

03

Rich Markdown

Task lists, footnotes, math, diagrams and emoji out of the box.

04

SEO built-in

Sitemaps, RSS/Atom feeds, OpenGraph, auto OG images and JSON-LD.

05

Client-side search

Fuse-powered search with CJK tokenization for Korean and beyond.

06

i18n & assets

Multilingual routing, responsive images, CSS/JS bundling and fingerprinting.

Quickstart

One command from Markdown to a deployable site

zsh
$ brew install hwaro
# build the site from content/
$ hwaro build
[*] 142 pages · 38 assets bundled
[*] Site built in 1.18s
# or live-reload while you write
$ hwaro serve --open
