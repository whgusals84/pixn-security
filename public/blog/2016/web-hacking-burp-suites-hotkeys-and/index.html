BurpSuite의 단축키(Hotkey) 소개 및 변경하기

AUGUST 23, 2016

Offensive Security Engineer, Developer and H4cker.

개인적으로 웹 해킹 시 주력으로 사용하는 툴은 Burpsuite 입니다. 아 물론 최근 ZAP(OWASP Zed Attack Proxy)를 사용해봤는데 굉장히 좋더군요. 그래도 손에 익은 단축키와 저에게 맞는 UI로 저는 Burp의 손을 들어주고 싶네요.

오늘은 Burpsuite의 단축키에 대해 정리할까 합니다. 물론 툴에서도 쉽게 확인할 수 있지만 페이지로 정리해두면 참고하기 좋습니다 :D

Edit HotKey

Burp는 단축키 변경으로 개인의 스타일에 맞게 편리한 사용을 지원합니다. 일단 요약해서 설명드리면 Options > Misc > Hotkeys > Edit hotkeys 입니다.

먼저 Options으로 들어가줍니다.

Options 탭으로 들어가면 하단에 Connections, HTTP, SSL, Sessions, Display, Misc의 탭이 보입니다. 이 중에서 Misc 탭으로 들어갑니다. 접근하게 되면 맨 위에 Hot Keys 항목이 보입니다.

여기서 Edit hotkeys를 눌러보시면 지정 안된 단축키들도 많이 보입니다. 여기서 하나하나 편집해주시면 됩니다.
