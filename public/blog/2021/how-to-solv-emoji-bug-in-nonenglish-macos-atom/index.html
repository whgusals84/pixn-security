MacOS Atom에서 이모지 사용 불가 버그 해결하기

FEBRUARY 7, 2021

Practical web security knowledge, secure engineering references, and open-source tools.

Atom을 사용하던 중 은근히 불편한 부분이 하나 있었습니다. 바로 이모지를 사용할 수 없는 이슈인데요. 고쳐서 써야지 하다가 이제서야 솔루션을 찾아보고 적용해서 사용하니 패치 전까진 임시방편으로 쓸만한 것 같아 글로 간단하게 공유드립니다.

Problem

맨 처음 이야기드린대로 이모지가 사용 불가능한 이슈가 있었습니다. 좀 더 정확하게는 비 영어권(시스템 기본 언어가 english가 아닌)의 Atom에서만 재현되는 이슈로, 아직 공식적으로 패치가 나온 것 같진 않습니다. (2018년도 이슈인데..?)

아무튼 저도 기본언어는 한글로 놓고 사용하는 상태라 당연히 이모지 사용이 불가능했던 거구요. 개발자들의 추측 상 Electron의 버그이지 않을까 싶다고 하네요..

아무튼 그래서 단축키나 터치바로도 사용이 불가능하고, Edit 메뉴에도 Emoji & Symbols 항목은 없습니다.

Solution

MacOS 카탈리나 이후부턴 언어 및 지역 설정을 앱 별로 사용자화하여 지정할 수 있습니다. 이를 이용해 Atom을 English 로 바꾸면 기존 English 환경에서는 잘 동작하기 떄문에 이모지를 사용할 수 있어집니다.

설정 > 언어 및 지역 > 앱 > + 를 통해 추가 > Atom을 영어로 변경

시스템 설정에서 언어 및 지역으로 들어갑니다.

앱 탭을 선택한 후 + 버튼을 눌러 Atom앱을 영어로 바꿔줍니다.

Atom 리부팅 이후부터 영어 버전으로 바뀌며 Edit에 Emoji & Symbols가 나타납니다.

이제 단축키로도 잘 사용할 수 있습니다 😍
